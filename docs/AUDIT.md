# Технический аудит исходного файла «Реестр договоров Снабжения.xlsx»

Аудит выполнен автоматически (ExcelJS) и воспроизводится тестом `packages/shared/test/import.test.ts`
(запуск с `PF_REAL_XLSX=<путь к файлу>`). Сам файл в репозиторий не входит.

## Структура

| Лист | Состояние | Назначение |
|---|---|---|
| Реестр договоров | 898 строк, 48 физ. столбцов | Реестр. Заголовок — строка 5; над ним строка 3 (месяц) и 4 (W1–W4) |
| Лист4 | скрытый, пустой | Не данные; в мастере импорта недоступен |
| Расчёт | 11 строк | Свод долга по валютам и свой блок курсов |

Поля C:AN: Проект, Номер контракта, Контрагент, Товар, Сумма, Оплачено, Остаток (формула `IF(G-H=0,"",G-H)`), Валюта,

## Находки, влияющие на финансы

1. **5 договоров с суммой и без валюты.** Итоги источника (`SUMIFS` по валюте) их **не учитывают** — их остаток выпадает из «Итоговой задолженности». В системе такие строки блокируются, пока пользователь не выберет валюту.
2. **Два блока курсов расходятся** (разные даты и значения USD/EUR/RUB на листе «Реестр» и на листе «Расчёт»). Курс автоматически не выбирается — см. раздел «Курсы валют».
3. **Итоговые формулы источника повреждены:** в блоке на листе «Реестр» `F892=F891`, `F893=F891`, `F894=F891` при других кэшированных значениях.
4. **Расхождение остатка:** в 4 строках значение колонки «Остаток» ≠ «Сумма − Оплачено» (предупреждение `DEBT_MISMATCH` в отчёте импорта); в расчёте всегда используется «Сумма − Оплачено», значение источника сохраняется для сверки.
5. **Недельные колонки:** в 591 строке с нулевым остатком они заполнены — вероятно, это история платежей, а не план; в 29 строках там текст («Оплата переводится согласно поручению Руководства»), он сохраняется как примечание к плану.
6. Валюта `EURO` (1 строка) — приводится к EUR с пометкой в отчёте; 49 групп поставщиков отличаются только регистром/кавычками/пробелами/ИНН.
7. Даты договоров есть только внутри текста номера (469 строк); при нескольких датах в одной строке (113) дата не определяется автоматически.
8. 20 значений «Оплачено» — формулы вида `197524+65016`; используется сохранённый результат, формула хранится.

## Контроль точности

Пересчёт «Сумма − Оплачено» по валютам совпадает с контрольными итогами самого файла для всех четырёх валют (по UZS допустима разница в доли единицы из-за float-шума в источнике).
